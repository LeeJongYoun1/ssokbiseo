## 2. 저장소 받기

경로는 `C:\_vibe\ssok-biseo`로 맞추는 것을 권한다. 다른 경로여도 되지만, 그러면 Claude Code의 예전 대화 기록과 메모리는 이어지지 않는다. 이 문서가 그 내용을 대신한다.

```powershell

cd C:\_vibe\ssok-biseo
git checkout feat/initial          # 작업 브랜치. main에는 문서만 있다
```

브랜치는 세 개다.

| 브랜치 | 용도 |
|---|---|
| `feat/initial` | 실제 작업 브랜치. 한 단계가 끝날 때마다 여기에 푸시 |
| `main` | 설계 문서만 있다. feat/initial을 main에 합치는 일은 **사용자에게 묻고 나서** 한다 |
| `apk` | 테스트용 APK 배포 전용. README의 "바뀐 점"을 함께 고친다 |

## 3. 서명 키 (쏙메모와 같은 키)

쏙비서는 쏙메모와 같은 키로 서명한다. 키가 없으면 release 빌드가 일부러 실패한다(`app/android/app/build.gradle.kts`).

1. 쏙메모 안내(`memoOurbousApp` 저장소 `docs/handoff/new-pc-setup.md` 3장)대로 Google Drive에서 `ssokmemo-temp.jks`와 `key.properties`를 받는다. jks는 `%USERPROFILE%\.ssokmemo-keys\`에 둔다.
2. 그 `key.properties`를 **`C:\_vibe\ssok-biseo\app\android\key.properties`에도 한 부 복사**한다. `storeFile` 경로는 새 PC 사용자 이름에 맞게 슬래시(`/`)로 쓴다.
3. 이 파일은 gitignore에 들어 있다. 절대 add하거나 커밋하지 말고, 내용을 채팅에 붙여 넣지도 않는다.

## 5. 테스트용 APK 올리기 (apk 브랜치)

```bash
git worktree add ../biseo-apk apk           # 한 번만
cd ../biseo-apk && git pull
git rm ssokbiseo-demo-<이전버전>.apk
cp ../ssok-biseo/app/build/app/outputs/flutter-apk/app-release.apk ssokbiseo-demo-<새버전>.apk
# README.md: '최신' 링크의 버전을 바꾸고 '바뀐 점' 맨 위에 한 줄 추가
git add -A && git commit -m "apk: <새버전> (...)" && git push origin apk
curl -sL -o /dev/null -w "%{http_code} %{size_download}\n" https://github.com/LeeJongYoun1/ssokbiseo/raw/apk/ssokbiseo-demo-<새버전>.apk
```

- 버전은 `app/pubspec.yaml`의 `version:`을 1씩 올린다(예: 1.0.13+14 → 1.0.14+15).
- curl 결과가 "200 0"이면 GitHub 캐시가 아직 갱신되지 않은 것이다. 잠시 뒤 다시 확인한다.
- 버전은 `aapt2 dump badging <apk>`로 확인한다. Windows 경로로 넘겨야 한다.

## 6. 지금까지 한 일 (상태)

**앱**: 아침 한 화면 비서. 쏙메모의 형제 앱이고, 패키지는 `com.ssokmemo.biseo`이다.

- 날씨(기상청)는 집·회사 기준이다. 지금 위치가 집이나 회사에서 10km 밖이면 '내 위치'를 맨 앞에 붙인다. 위치마다 3시간 간격 6칸 예보가 있다.
- 일정은 기기 캘린더에서 읽는다(device_calendar). release 빌드에서는 R8 keep 규칙이 필요하다(`app/android/app/proguard-rules.pro`).
- 출근 시간은 카카오 API로 차와 대중교통 시간을 구하고, 누르면 카카오맵이 열린다.
- 기분 5개 × 말투 조언, 관심 뉴스 12개 주제, 커뮤니티(GeekNews·뽐뿌·루리웹·82cook), 세무 소식(세정일보, 국세청 보도자료·공지사항)은 매일 아침 Claude 예약 루틴(Haiku)이 만드는 `data/briefing.json`에서 읽는다.
- 유튜브 새 영상은 설정에서 등록한 채널의 RSS로 가져온다. 키가 필요 없다.
- 설정에서 집·회사, 주제, 말투, 커뮤니티, 세무 소식, 유튜브 채널을 고른다.

**구조 (방안 A)**:
- `server/`: Vercel 함수(TypeScript). API 키를 보관하고, `weather`·`geocode`·`route`·`news-raw` 엔드포인트와 Supabase 하루 사용량 제한(2026-11-07 Upstash에서 변경)을 맡는다.

## 8. 작업 규칙 (사용자와 합의한 것)

- 한국어로 짧고 쉽게 답한다. 사용 설명은 어르신도 읽을 수 있게 쓴다.
- 한 단계가 끝날 때마다 `feat/initial`에 푸시한다. 사용자가 시험해 볼 만한 변경이면 apk 브랜치에 새 APK도 올린다.
- main에 합치는 일, 앱 삭제, 프로세스 종료 같은 되돌리기 어려운 일은 먼저 묻는다.
- 키 파일(`key.properties`, `.jks`)은 커밋하지 않고, 내용을 출력하지도 않는다.
- 연락처 메일은 개인정보처리방침과 Play 연락처에만 쓴다.
- 작업 기록 장부 `.superpowers/sdd/…/progress.md`는 gitignore 대상이라 새 PC에는 없다. 이 문서가 그 요약이다.
