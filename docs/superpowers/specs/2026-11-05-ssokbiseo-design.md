# 쏙비서 설계 (2026-11-05)

쏙메모의 형제 앱. 새 저장소, 새 Flutter 프로젝트로 만든다. 이 문서는 아이디어 단계에서 사용자와 정한 내용을 담는다.

## 1. 무엇을, 왜

- **한 줄:** 아침에 일어나 앱을 한 번 열면 그날 필요한 정보 여섯 가지를 한 화면에서 본다.
- **왜:** 사용자는 아침마다 날씨·일정·뉴스·커뮤니티·출근 시간을 여러 앱을 오가며 확인한다. 이를 한 번에 보고 싶다.
- **누가:** 사용자 본인과 지인(쏙메모를 쓰는 지인들 포함). 쏙메모처럼 APK로 나눠 준다.
- **룩앤필:** 쏙메모와 같은 형제 느낌. 레몬색·크림 바탕·"쏙" 배지·Jua 제목 글꼴·큰 글씨. 색 값은 쏙메모 `lib/ui/theme.dart`의 `SsokColors`를 그대로 가져온다.

## 2. 기능 (사용자가 정한 것)

| # | 기능 | 데이터 출처 | 언제 만들어지나 |
|---|---|---|---|
| 1 | 집·회사 날씨 | 기상청 단기예보 API(공공데이터포털) | 앱을 열 때, 중계 서버 경유 |
| 2 | 오늘 일정 | 휴대폰 일정 저장소(Android CalendarContract). 구글 캘린더·삼성 캘린더가 함께 보임 | 앱을 열 때, 기기 안에서 |
| 3 | 관심 뉴스 | 네이버 검색 API(뉴스). **정해 둔 주제 목록**마다 최신 기사 10개 → Haiku가 요약 | 매일 아침 예약 작업 |
| 4 | 기분별 조언 | Haiku. **기분 5가지 × 말투 4가지 = 20개**를 매일 새로 생성 | 매일 아침 예약 작업 |
| 5 | 커뮤니티 인기글(GeekNews·뽐뿌·루리웹·82cook, 설정에서 홈에 보일 곳 선택) | 어제 올라온 글 중 **추천/점수/조회수 높은 순 10개**(순위 정보가 없으면 최신 10개) → Haiku 요약 | 매일 아침 예약 작업 |
| 6 | 집·회사까지 걸리는 시간 | **카카오**: 자동차는 카카오모빌리티 길찾기, 대중교통은 카카오맵 대중교통 경로 API | 앱을 열 때, 중계 서버 경유 |

세부:
- **3번:** 공식 API만 쓴다(랭킹 페이지 긁어 오기 안 함). 주제는 예약 작업이 공통으로 만들고, 각자 설정에서 볼 주제를 고른다. 주제 후보: 경제, 재테크, 세무, 부동산, 건강, IT, 정치, 스포츠 등 12개.
- **4번:** 기분은 버튼으로 고른다(직접 글로 적지 않음). 기분: 좋음 😊, 피곤 😴, 걱정 😟, 우울 😢, 의욕 🔥. 말투는 **설정**에서 고른다: 다정한 친구 / 짧고 힘 있는 코치 / 명언 인용 / 오늘 해 볼 작은 행동.
- **5번:** 목록은 제목만. 누르면 요약, 요약 안의 링크를 누르면 원문 페이지로 이동.
- **6번:** 출발점은 현재 위치, 도착점은 설정에 등록한 장소(집, 회사). 자동차·대중교통 시간을 숫자로 보여 주고, 누르면 카카오맵 앱 길찾기로 넘어간다.
- **장소 등록:** 집·회사 주소는 설정에서 한 번 등록하고 1번 날씨와 6번 길찾기가 함께 쓴다.
- **요약의 재료(사용자 결정):** 네이버 검색 API가 주는 **제목 + 미리보기**만으로 기사마다 한 줄 요약을 만든다. 언론사 본문은 가져오지 않는다. GeekNews는 글 페이지의 **작성자 소개 글**만 읽어 요약한다.
- **한도 초과 시(사용자 결정):** Vercel이 하루 호출 수를 세어 카카오 대중교통 **900건**쯤에서 그날은 막는다. 막힌 날은 "오늘은 확인할 수 없어요" + 카카오맵 열기 버튼만 보인다. 유료 결제는 연결하지 않는다(비용 0원 유지). 호출 수 저장용으로 Vercel의 무료 저장소(KV 등)를 하나 쓴다.

## 3. 구조 (선택한 방식 A)

```
Vercel 수집 엔드포인트 (네이버 키 보관) ── 주제별 기사 목록(제목·미리보기·링크)
                                   ↓ 읽기
Claude 클라우드 예약 작업 (매일 아침, Haiku, 사용자 구독) ── 요약만 함
   └→ 3·4·5번 결과를 JSON 파일 하나로 GitHub 저장소에 커밋
                                   ↓ 읽기(공개 URL)
쏙비서 앱 (Flutter, Android)
   ├ 2번 일정: 기기 안에서 직접
   └ 1·6번: Vercel 중계 서버(무료 Hobby, API 키 보관) → 기상청·카카오
```

## 4. 검토한 방식

| 방식 | 내용 | 결과 |
|---|---|---|
| **A (선택)** | 앱 + Vercel 중계 서버 + Claude 예약 작업 | 정한 내용을 모두 지킨다: 예약 작업은 구독, 키는 앱 밖, 지인 배포 가능. 관리할 곳이 셋 |
| B | Vercel이 예약까지 모두 처리 | 단순하지만 AI를 Claude API 키로 결제해야 함 → 4번을 구독으로 하자는 결정과 맞지 않음 |
| C | 앱이 모든 API 직접 호출 | 가장 빠르지만 키가 앱에 들어가 지인 배포 시 한도 도용 위험 → 제외 |

## 5. 제약

- **비용 0원 목표:** Vercel Hobby(비상업 용도만, 광고 넣으면 Pro 필요), 카카오 대중교통 하루 1,000건 무료(첫 번째로 활성화한 앱만, 초과 건당 10원), 네이버 검색 API 하루 25,000건, 기상청 API 무료.
- **AI는 사용자의 Claude 구독 예약 작업**으로 시작한다. 구독은 개인 사용용이라 지인용 콘텐츠 생성이 약관에 어긋날 수 있다. **지인이 늘면 Claude API(Haiku) 키로 옮기는 것을 다시 검토한다**(그때는 방식 B처럼 Vercel 예약으로 이전).
- **API 키는 앱에 넣지 않는다.** 기상청·카카오 키는 Vercel 환경변수에.
- **GitHub의 JSON은 공개**이므로 개인정보를 넣지 않는다(뉴스·조언·GeekNews만). 일정·위치는 기기 밖으로 보내지 않는다. 단, 6번은 현재 좌표가 Vercel→카카오로 전달된다.
- **권한:** 인터넷, 일정 읽기(READ_CALENDAR), 위치(현재 위치용). 쏙메모와 달리 인터넷을 쓴다.
- **배포:** 쏙메모처럼 APK. 패키지 이름은 쏙메모(`com.ssokmemo.app`)와 겹치지 않게 새로 정한다.
- **약관:** 네이버는 공식 검색 API만. GeekNews는 공개 페이지에서 제목·점수·링크만 읽는다.

## 6. 하지 않는 것

- 기분을 글로 직접 적기(서버에서 실시간 AI 호출 필요)
- 네이버 "많이 본 뉴스" 랭킹 긁어 오기
- 아이폰판, 광고, 로그인·계정
- 사람별 맞춤 AI 생성(모두 같은 콘텐츠를 받고, 앱에서 고르기만 함)

## 7. 실패로 보는 것

- 아침에 열었는데 화면이 비어 있거나 한참 기다려야 함
- 지인 배포 후 누군가 키를 꺼내 무료 한도가 바닥남
- 일정·위치 같은 개인정보가 공개 저장소에 올라감

## 8. 설계자 판단 (사용자 확인 대상)

- **네이버 키는 예약 작업에 넣지 않는다.** Vercel이 기사 목록을 모아 주고 예약 작업은 요약만 한다. 예약 작업이 GeekNews나 Vercel에 접속하지 못하면 그때 다시 정한다(방식 B로 옮기는 것은 비용이 생기므로 사용자 결정).
- **카카오 대중교통 응답에 소요 시간이 없으면** 대중교통 칸은 숫자 없이 카카오맵 대중교통 길찾기 버튼만 둔다. 자동차는 숫자로 보인다.
- **예약 작업이 실패한 날**은 전날 내용을 "어제 내용이에요" 표시와 함께 보여 준다.

## 9. 만드는 사람에게 맡긴 것

- 예약 작업 실행 시각, JSON이 올라갈 저장소와 형식
- 화면 배치(여섯 칸의 순서와 모양)
- 주소 → 좌표 → 기상청 격자 변환 방법
- 새 저장소 이름, 공개 여부, 패키지 이름(만들기 전에 사용자에게 확인)
- Claude 예약 작업에서 Haiku 모델을 고를 수 있는지(확인 필요)
- 카카오 대중교통 응답에 소요 시간 필드가 있는지(문서 확인 필요)
